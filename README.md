# КТЖ SmartRailway AI

Прототип системы поддержки решений для диспетчера и машиниста: автодиспетчеризация и советующее автоведение (Advisory ATO) на направлении Астана — Караганда — Алматы.

**Живая демо-версия:** https://noob491.github.io/ktzh-smartrailway/

> Прототип носит консультативно-рекомендательный характер (Decision Support System) и не заменяет сертифицированные системы СЦБ и АЛСН.

## Что умеет

- **Карта и мониторинг.** Поезда на магистрали КТЖ в реальном времени, слои пассажирских и грузовых поездов, красные зоны (ремонт, занятость), фильтр по статусу: в графике, отклонение, критично.
- **Поездограмма.** График «время × станции»: нормативный план пунктиром и прогноз без вмешательства сплошной линией, технологические окна и закрытые перегоны.
- **Автоведение (ATO).** Профиль скорости на участке Караганда — Агадырь: ограничения, рекомендация ИИ и фактическая скорость, подсказка машинисту (например, выбег), прогноз прибытия и экономия энергии.
- **Индекс качества движения.** Интегральная оценка 0–100 с зонами «Норма / Внимание / Критично», динамика за час и Top-5 факторов влияния с подтверждением по данным.
- **Симулятор нештатных ситуаций.** Поломка поезда (+45 мин), закрытие перегона Астана — Караганда, сброс к норме. Мастер ИИ-диспетчера предлагает варианты перепланирования.

## Как запустить

Ничего устанавливать не нужно: это одна HTML-страница.

- Онлайн: откройте ссылку на демо выше.
- Локально: скачайте `index.html` и откройте двойным щелчком в Chrome, Edge или Firefox. Нужен интернет для карты, шрифтов и библиотек.

## Технологии

HTML, CSS (Tailwind), JavaScript, Leaflet (карта), Apache ECharts (графики). Сервер не нужен, данные поездов моделируются прямо в браузере.

## Ограничения прототипа

- Данные демонстрационные: поезда, задержки и телеметрия сгенерированы симулятором.
- Подложка карты подключена напрямую с серверов Google; для промышленной версии нужна лицензированная картографическая подложка.
